# Data-Cleaning-using-Python-Pandas-library
📌 Project Overview
This project focuses on cleaning and preparing a synthetic diabetes dataset using Python and Pandas.
The goal was to take raw, unprocessed healthcare data and transform it into a cleaner and more consistent dataset that can be used for further data analysis, visualization, and machine learning.
The project was completed using Python in Visual Studio Code (VS Code).

🎯 Objectives
#The main objectives of this project were:
#Understand the structure of the raw dataset
#Inspect the dataset for missing and inconsistent values
#Identify potential data quality issues
#Clean and preprocess the data using Pandas
#Improve data consistency and usability
#Prepare the dataset for future analysis or machine learning

🛠️ Tools & Technologies
#Python
#Pandas
#Jupyter notebook in VS Code
#Visual Studio Code
#CSV dataset generated using Claude AI

📂 Dataset
The dataset used in this project is a synthetic diabetes dataset created for practice and learning purposes using GenAI Anthropic Claude.
It contains patient-related information and diabetes-related attributes.

🔍 Data Cleaning Process
The dataset was examined and cleaned using Python and Pandas.
The general workflow included:
1. Loading the Dataset
2. Initial Data Inspection
3. Checking Missing Values
4. Checking Duplicate records
5. Data Type & Consistency Checks
6. Data Cleaning
